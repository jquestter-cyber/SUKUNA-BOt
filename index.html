# SUKUNA V1000 SUKUNA V1000 is a powerful WhatsApp bot starter with: - admin commands - group suspension control - sticker creation from images - live status endpoints - modern landing page ## Features - `!menu` — show commands - `!status` — status of bot - `!suspend` — suspend a group - `!resume` — resume a group - `!sticker` from image caption — convert image to sticker - bot health endpoint ## Install ```bash npm install ``` ## Run ```bash npm start ``` Then open: ```bash http://localhost:3000 ``` Scan the QR code in terminal with WhatsApp. ## Sticker command Send an image with caption: ```bash !sticker ``` The bot will convert it into a WhatsApp sticker. ## Notes This is a starter bot. You can extend it with AI, database, anti-spam, and dashboard features. ## License MIT
