# SUKUNA BOT

SUKUNA BOT is a modern WhatsApp bot starter project built to be real, extensible, and easy to run locally.

## What this project includes

- A landing page for the SUKUNA brand
- An Express web server
- A WhatsApp bot starter using Baileys
- Simple health/status endpoints
- Environment-based configuration

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the app:
   ```bash
   npm start
   ```
3. Open the site:
   - http://localhost:3000
4. Scan the QR code in the terminal to connect the WhatsApp bot.

## Project structure

- `index.html` – landing page
- `server.js` – Express server + WhatsApp bot logic
- `.env.example` – example environment variables
- `package.json` – dependencies and scripts

## Notes

This project is intended as a working starter template. To use WhatsApp features, you need a valid WhatsApp session and a device connected via QR code.
